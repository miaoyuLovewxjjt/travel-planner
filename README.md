# 🌍 我的行程（个人旅行规划工具）

> **🔄 分支策略（重要）**：本分支（`master`，网页版）**独立维护**，
> **不再与安卓版（`android` 分支）同步**；安卓版页面为独立代码。
> 两套可以各自演进不同的设计与功能，互不影响。


一个本地运行的个人旅行规划工具：管理**大行程**，自动按日期排列**每日行程**，支持路线 / 跨天行程 / 住宿 / 出行人 / 备注 / 记账 / 消费圆环图 / 每日总览，一键生成 **Ins 风格全量预览** 与**带目录的 PDF 文档**，可打包为 Android App（手机版 + 平板 HD 版）。

## ✨ 功能

| 功能 | 说明 |
|------|------|
| 大行程 | 新建 / 编辑 / 删除，含名称、日期范围、出行人、预算、主题色、渐变壁纸（行程级独立配色）、封面表情 |
| 每日自动排列 | 详情页按日期自动排序，左侧日期导航，点击滚动到当日全部行程 |
| 行程路线 | 多段 `a → b → c`，每段含出发/到达时间（直接输数字、冒号自动就位、退格删数字冒号保留）、交通方式（🚇地铁 ✈️飞机 🚕打车 🚌公交 🚶步行 🚄高铁 🚗自驾 🚙租车 🛥️游船 🚲骑行）、价格、备注；时间/地点/交通三列对齐展示 |
| **跨天行程** | 到达早于出发自动标 `(+1)`（**任何交通方式均提示**），支持编辑 +2/+3/+4 天；时长按日拆分，次日总览自动追加"接昨日"续段 |
| 交通详情 | 高铁/飞机自动展开：班次/车次、**乘客与座位一一挂钩**、花销、跨天 |
| 住宿 | 类型（酒店🏨/民宿🏡/青旅🛏️/其他🏠）、名称、位置、每晚价格、备注；✓ 提交模式，可编辑/删除 |
| 备注 | 每日自由文本备注（每日卡片最上方，限 80 字） |
| 记账 | 每日花销明细（类别/项目/金额/时间/备注，限 30 字）；路线与住宿价格**自动计入**当日花费，不在记账区重复展示 |
| **消费圆环图** | 按类别占比环形图（**每类固定颜色**，不随主题变化），点击类别展开每一笔明细 |
| 拖动排序 | 花销与路线左侧手柄「≡」鼠标拖拽自由排序；单条记录删除免确认 |
| 行程总览 | 住宿、出行人、路线分段条形图（颜色跟随主题色渐变） |
| Ins 预览 | 可爱风格封面（漂浮装饰）+ 每日时间线 + 真实地图 + **点击某天跳转到具体行程**；可下载 PNG 留作纪念 |
| PDF 文档 | 带目录（标题即日期、可点击跳转），每日含备注/提醒表/路线表（班次/乘客/座位/价格分列、空值 `—`）/住宿/记账表/每日总结（花费/时长/出行人）；打印存 PDF |
| **行程主题** | 每个大行程创建时选择**主题色与渐变壁纸**，详情页/旅行记录/PDF 全部跟随该行程配色，互不影响；应用外观不再有全局主题 |
| 数据管理 | 顶栏 ⚙️ 设置：存储路径 / 占用 / 导出导入 / 一键清理（双确认） |

## 🚀 快速开始（网页版）

```bash
# 1. 启动服务（需要 Node.js，零依赖）
node server.js

# 2. 浏览器打开
http://localhost:7788
```

- 首次启动自动创建示例数据 `data/trips.json`，可直接体验
- 数据保存于 `data/trips.json`（原子写入），所有修改自动保存
- API：`GET/PUT /api/trips`、`GET /api/info`（数据路径）、`GET /api/health`
- 浏览器无法连接服务时自动降级为 localStorage（APK 内即是此模式）

## 📱 Android App（自行打包）

> APK 不随仓库发布，需要的人自行用 Android 工程打包。

## 🌿 分支说明（三端同步）

| 分支 | 内容 |
|------|------|
| `master` | **PC 网页版**：`app.html` + `server.js`（功能单一事实源） |
| `android` | **安卓版**：`android/android-app`（手机）+ `android/android-app-hd`（平板 HD）工程，`assets/index.html` 与 master 的 `app.html` 保持同步 |

**三端同步维护流程**：新功能先在 `master` 更新 `app.html` → 切到 `android` 分支合并/同步最新页面 → `assets/index.html` 更新 → 本地打包 APK。PC 网页 / 安卓手机 / 安卓平板三端始终同一套代码。

### 打包

```bash
# 需要 JDK 17 + Android SDK 34
cd android/android-app            # 或 android-app-hd
gradle assembleDebug
# 产物：app/build/outputs/apk/debug/app-debug.apk
```

- 数据存于 App 私有存储（localStorage），与电脑版通过「📤 导出 / 📥 导入」互通
- 导出文件自动保存到手机「下载」目录并弹出分享；离线可用（地图/PNG 导出需联网）

## 💾 数据迁移

电脑 ⇄ 手机：任意一端「📤 导出」得到 JSON 文件 → 另一端「📥 导入」即可，格式通用。

## 🗺️ 技术细节

- 纯前端单文件 `app.html`（HTML/CSS/JS，无框架、无构建步骤）
- 地图：Leaflet + 高德免费瓦片（国内快、中文标注），失败自动降级 OpenStreetMap
- WebView 壳：Android Java + androidx.activity，零额外依赖
- 跨天行程：`crossDays` 字段（0=当天，N=跨 N 天），自动检测 + 手动可编辑
- 行程级主题：每个大行程的 `color`/`wall` 字段驱动详情页/旅行记录/PDF 的 CSS 变量（`--accent` 系列自动派生浅色渐变端/柔和底/描边/阴影），行程间互不影响
- 时间输入：数字自动补冒号（`0900 → 09:00`），退格删数字且冒号保留，纯冒号占位不写入数据
