# 🌍 我的行程（个人旅行规划工具）

> **🔄 双端仓库结构（v1.0，2026-08-28）**：
> - **`master`** — 网页版（`app.html` + `server.js`，端口 7788）
> - **`android`** 分支 — 安卓原生版（`travel-planner-android/`，纯 Java 零依赖）
> - 版本标签：**`v1.0`（网页版）** / **`v1.0-apk`（安卓版）**；两端数据格式完全同构（`trips.json`），导出/导入互通，未知字段原样保留。

一个本地运行的个人旅行规划工具：管理**大行程**，自动按日期排列**每日行程**，支持路线 / 跨天行程 / 住宿 / 出行人 / 备注 / **天气** / 记账 / 消费圆环图 / **行李收纳模拟** / **行程总结**，一键生成**带目录的 PDF 文档**（导出前可预览）。

## ✨ 功能（网页版 v1.0）

| 功能 | 说明 |
|------|------|
| 大行程 | 新建 / 编辑 / 删除，含名称、日期范围、出行人、预算、主题色、渐变壁纸（行程级独立配色）、封面表情 |
| 每日自动排列 | 详情页按日期自动排序，左侧日期导航，点击滚动到当日全部行程 |
| 行程路线 | 多段 `a → b → c`，每段含出发/到达时间（数字自动补冒号）、交通方式（12 种）、价格、备注；**车次图标跟随该段实际交通**（高铁段 🚄、飞机段 ✈️） |
| 跨天行程 | 到达早于出发自动标 `(+1)`，支持编辑 +2/+3/+4 天；时长按日拆分，次日总览自动追加"接昨日"续段 |
| 交通详情 | 高铁/飞机自动展开：班次/车次、**乘客与座位一一挂钩**、花销、跨天 |
| 住宿 | 类型（酒店🏨/民宿🏡/青旅🛏️/其他🏠）、名称、位置、每晚价格、备注；✓ 提交模式 |
| 天气 | 每日可设置天气徽章（晴/多云/阴/雨/雷阵雨/雪/雾/风 + 最低/最高温），显示于每日卡片顶部，PDF 导出一并带上 |
| 备注 | 每日自由文本备注，完整显示 |
| 记账 | 每日花销明细（类别/项目/金额/时间/备注）；路线与住宿价格**自动计入**当日花费（只读行标注「路线」「住宿」来源）；**当日总金额写在标题旁**，不入圆环 |
| 消费圆环图 | 按类别占比环形图（每类固定颜色）；图例点击**就地展开**每一笔明细（不弹窗） |
| 行李清单 | 🎒 计划携带物品：分类 / 重要性 / 备注，**放入的行李袋在编辑行内选择**（状态由袋自动派生：有袋=已携带、无袋=未携带）；🧳 行李携带可行性模拟：自定义行李箱/手提袋，物品拖入收纳、✕ 移回物品池、一键同步 |
| 每日导航 | 日期列表可折叠（**默认折叠**）；行李清单页点日期仍可跳转当天 |
| 行程总结 | 全局总览页（只读）：住宿晚数/路线段数、各交通方式统计与**在途时长分布**、**预算使用**（置于消费构成上方，无冗余百分比）、消费构成环图（图例点击就地展开跨日明细） |
| PDF 文档 | 带目录，每日含备注/提醒表/**路线表**/住宿/**记账表**/每日总结（**天气并入每日标题行**）；导出前有**预览**；之后附带行程总结章节 |
| 数据管理 | 顶栏 ⚙️ 设置：存储路径 / 占用 / 导出导入 / 一键清理（双确认） |

## 🚀 快速开始（网页版）

```bash
# 1. 启动服务（需要 Node.js，零依赖）
node server.js

# 2. 浏览器打开
http://localhost:7788
```

- 首次启动自动创建示例数据 `data/trips.json`，可直接体验
- 数据保存于 `data/trips.json`（原子写入），所有修改自动保存
- API：`GET/PUT /api/trips`、`GET /api/info`（数据路径）、`GET /api/health`
- 浏览器无法连接服务时自动降级为 localStorage（离线可用）

| 分支 | 内容 | 标签 |

## ✌️ v1.0 亮点（2026-08-28 · 双端封板）

- 网页版与安卓版**功能/数据/文案完全一致**：天气、行李收纳池、总结就地展开、PDF 含天气、记账标题旁总金额（不入圆环）
- 安卓原生版：图标徽章统一尺寸、emoji 垂直居中、顶栏图标与标题同高；构建 `gradle assembleDebug --offline --no-daemon`
- 导出 PDF：每日标题行带天气；章节标题与页面一致（🗺️ 行程路线 / 🏨 住宿 / 🧾 记账 / ⏰ 提醒）
- 主题色 10 预设：每行程独立配色，详情页/PDF 全跟随

## 💾 数据迁移

电脑 ⇄ 手机：任意一端「📤 导出」得到 JSON 文件 → 另一端「📥 导入」即可，格式通用（未知字段保留）。

## 🗺️ 技术细节

- 纯前端单文件 `app.html`（HTML/CSS/JS，无框架、无构建步骤）
- 行程总结：聚合统计复用每日行程/记账数据（不新增数据字段、纯展示）；环形图用纯 CSS（打印稳定）
- 跨天行程：`crossDays` 字段（0=当天，N=跨 N 天），自动检测 + 手动可编辑
- 行程级主题：`color`/`wall` 字段驱动详情页/PDF 的 CSS 变量（`--accent` 系列自动派生）
- 天气：`day.weather = {cond, low, high}`，与安卓版同构
