# 🧳 我的行程 · 安卓版（原生）

> **本分支 = 平板适配版（android-hd）**：平板（sw≥600dp）自动放大 1.25×（图标/字号/圆角/间距），内容限宽 960dp 水平居中；手机（sw<600dp）行为与  分支完全一致。

基于 **travel-planner-web** 数据格式（`trips.json`）的**原生安卓版**（**v1.0**，纯 Java + Android 框架 Views，**零第三方依赖**）。

> **路线说明（2026-08-25 起）**：放弃 WebView 套壳方案（旧版把网页布局搬进手机，存在长文本被省略号截断的兼容问题）。
> 本版为原生开发：所有用户内容（路线地名/备注/项目名）**自动换行、完整显示、禁止省略号**，直接适配手机屏幕。

## 功能（v1.0 全量，与网页版功能/数据/文案完全一致）

| 功能 | 说明 |
|------|------|
| 大行程 | 新建 / 编辑 / 删除：「我的行程」列表（标题无 emoji、整卡点击进入）、名称/表情/日期范围/预算/出行人/主题色 10 预设色板 |
| 行程详情 | 渐变概览卡（花费/预算，超支红字）＋ 日期导航 chips（横向滚动，选中高亮行程主题色）＋ 三面板导航（每日/行李清单/总结） |
| 天气 | 每日天气徽章（**日期+周几 + 晴/多云/阴/雨/雷阵雨/雪/雾/风 + 最低/最高温**），点击弹窗设置/删除；字段 `day.weather` 与网页版同构 |
| 路线 | 出发地→到达地、时间、**跨天**（+1~+4）、交通方式 12 种（**图标跟随实际交通，车次 chip 同为该交通图标**）、价格、车次/座位/乘客、备注 |
| 住宿 | 类型（酒店🏨/民宿🏡/青旅🛏️/其他🏠）/名称/位置/每晚价格/备注 |
| 备注 | 当日自由文本，完整显示 |
| 记账 | 分类/项目/金额/时间；**标题行即总金额**（不入圆环）；交通/住宿自动计入（只读行「路线」「住宿」来源标签）；环图（分类图例点击**就地展开**明细，不弹窗） |
| 行李清单 | 🎒 计划携带物品（分类/重要性/备注，**袋在编辑框内选择**，状态由袋派生）；🧳 行李收纳模拟：**待收纳物品池**、物品拖入袋/✕移回池/一键同步「已携带」 |
| 行程总结 | 住宿晚数/路线段数/交通统计+在途时长占比条/**预算使用**（消费构成上方，无已使用百分比）/**消费构成环图**（图例点击就地展开跨日明细） |
| PDF 导出 | 🖨️ 顶栏按钮：**导出前全屏预览**（封面/目录/逐日含天气/行李/总结）→ 系统保存；章节标题与页面一致（🗺️ 行程路线 / 🏨 住宿 / 🧾 记账 / ⏰ 提醒），空值—、金额右对齐、长文换行、跨页重画表头 |
| 数据 | 存应用私有目录 `trips.json`；**导出/导入 JSON 与电脑网页版互通（导入=合并）**，未知字段原样保留 |
| 内容保真 | 所有 TextView 均 wrap_content、无 maxLines/ellipsize；文字超长自动换行、金额行可收缩、操作按钮固定右侧不换行；图标徽章 emoji 垂直居中、顶栏图标与标题同高（36dp）、行内 28dp |
| 内置示例 | 完整「2026 国庆新疆之旅」12 天示例（含天气/行李/路线/记账）；旧 demo 自动迁移清理（一次性） |

## 构建（离线，本机已验证）

```bash
# 需：D:/apkbuild 工具链（Android SDK android-34、gradle-dist 8.7、JDK 17）
cd travel-planner-android
"D:/apkbuild/android-tools/gradle-dist/bin/gradle" assembleDebug --offline --no-daemon
# 产物：app/build/outputs/apk/debug/app-debug.apk（或复制到 D:/apkbuild/dist/）
```

**坑位提醒**（已踩平）：
- `build.gradle` 的 buildscript 仓库必须保持镜像（腾讯云/阿里云）在 `google()` 之前——本地 Gradle 缓存是按镜像仓库 id 存的，离线解析才能命中。
- 依赖只允许用本地缓存里已有的（**无 Kotlin 插件、无 Compose、无 androidx 扩展**，纯框架）。

## 安装

- debug 包直接 `adb install app-debug.apk` 或拷到手机安装。
- 首次启动自动生成内置示例行程（与网页版同构）；老 demo 数据自动迁移（`Store.load()` 一次性）。
