# 🧳 我的行程 · 安卓版（原生）

基于 **travel-planner-web** 数据格式（`trips.json`）的**原生安卓版**（v3.1，纯 Java + Android 框架 Views，**零第三方依赖**）。

> **路线说明（2026-08-25 起）**：放弃 WebView 套壳方案（旧版把网页布局搬进手机，存在长文本被省略号截断的兼容问题）。
> 本版为原生开发：所有用户内容（路线地名/备注/项目名）**自动换行、完整显示、禁止省略号**，直接适配手机屏幕。

## 功能（一期）

| 功能 | 说明 |
|------|------|
| 大行程 | 新建 / 编辑 / 删除：名称、表情、日期范围（自动生成每日结构）、预算、出行人、备注 |
| 行程详情 | 概览卡（花费/预算，超支红字）＋ 日期导航 chips（横向滚动，选中高亮行程主题色） |
| 路线 | 出发地→到达地、时间（HH:mm 自动补零）、**跨天**（到达早于出发自动 +1，可显式 +2/+3/+4）、交通方式 10 种、价格、车次/座位/乘客、备注 |
| 住宿 | 类型（酒店/民宿/青旅/其他）/名称/位置/每晚价格/备注 |
| 备注 | 当日自由文本，完整显示 |
| 记账 | 分类（固定 6 类）/项目/金额/时间；当日合计；**Canvas 环形图**（分类图例点击展开该分类明细） |
| 行李清单 | 🎒 **计划携带物品**：分类（默认+自定义）/名称≤20/重要性（必需·非必需·待定）/已带·未带/备注，按品类自动分组；🧳 **行李收纳模拟**：3 个默认行李袋（可增删改名）、物品放入/移回、已收纳提示、一键同步为「已携带」 |
| 行程总结 | 📊 双级导航（每日/行李清单/总结）：住宿晚数/路线段数/交通方式统计+在途时长占比条/消费构成环形图（图例点开展跨日明细）/预算使用进度条 |
| PDF 导出 | 🖨️ 顶栏按钮：封面头→逐日章节（备注/住宿卡/**路线表**/**记账表**/每日总结行，表头浅灰底/空值—/金额右对齐/长文换行/跨页重画表头）→ 行程总结章节 |
| 数据 | 存应用私有目录 `trips.json`（无需权限）；**导出/导入 JSON 与电脑网页版互通（导入=合并：同名覆盖+新行程追加）**，未知字段原样保留 |
| 内容保真 | 所有 TextView 均 wrap_content、无 maxLines/ellipsize，任何长度文字全字显示；编辑/删除为网页版同款线条 SVG 图标（默认同灰一套、按压编辑蓝/删除红） |

## 构建（离线，本机已验证）

```bash
# 需：D:/apkbuild 工具链（Android SDK android-34、gradle-dist 8.7、JDK 17）
cd travel-planner-android
"D:/apkbuild/android-tools/gradle-dist/bin/gradle" assembleDebug --offline --no-daemon
# 产物：app/build/outputs/apk/debug/app-debug.apk（或复制到 D:/apkbuild/dist/）
```

**坑位提醒**（已踩平）：
- `build.gradle` 的 buildscript 仓库必须保持镜像（腾讯云/阿里云）在 `google()` 之前——本地 Gradle 缓存是按镜像仓库 id 存的，离线解析才能命中。
- 依赖只允许用本地缓存里已有的（**无 Kotlin 插件、无 Compose、无 androidx 扩展**，纯框架）。

## 安装

- debug 包直接 `adb install app-debug.apk` 或拷到手机安装。
- 首次启动自动生成示例行程（与网页版 seed 同构）。
